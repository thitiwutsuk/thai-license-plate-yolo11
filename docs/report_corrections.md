# ข้อเสนอแก้ไขรายงานโครงงาน (`docs/รายงานโครงงาน.pdf`)

เอกสารนี้สรุปจุดที่ **เนื้อหารายงานต้นฉบับไม่ตรงกับสิ่งที่ทำจริงแล้ว** พร้อมข้อความที่แนะนำให้แก้ไข — ไฟล์ต้นฉบับเป็น PDF ที่ export มาแล้ว ต้องแก้ที่ไฟล์เอกสารต้นทาง (Word/Canva/ที่ใช้ทำรายงาน) เอง แล้ว export ใหม่

## 1. แก้ไขส่วน 3.1 (แหล่งที่มาของข้อมูล)

### ข้อความเดิม (โดยสรุป)
> ถ่ายรูปรถเองทั้งหมด 250 คัน ด้วยโทรศัพท์มือถือ ตามเงื่อนไขของรายวิชาที่ไม่ใช้ชุดข้อมูลจากอินเทอร์เน็ต

### ข้อความที่แนะนำให้แก้เป็น
> เนื่องจากข้อจำกัดด้านเวลาและจำนวนรถที่หาได้ ได้ขออนุญาตอาจารย์ผู้สอนให้ใช้ข้อมูลรูปภาพจากอินเทอร์เน็ตเพิ่มเติมประกอบการทำโครงงาน โดยเก็บรูปภาพรถจำนวน 250 คัน จากแหล่ง Wikimedia Commons ซึ่งเป็นแหล่งรูปภาพที่เปิดให้ใช้งานภายใต้สัญญาอนุญาต Creative Commons (CC BY, CC BY-SA, CC0) ทุกรูปผ่านการตรวจสอบด้วยตาทีละรูปว่าเห็นป้ายทะเบียนชัดเจน เป็นป้ายทะเบียนไทยมาตรฐาน (ไม่ใช่ป้ายตกแต่ง/ป้ายโชว์/ป้ายต่างประเทศ) ก่อนนำเข้าชุดข้อมูล รายละเอียดแหล่งที่มาและสัญญาอนุญาตของทุกรูปบันทึกไว้ที่ไฟล์ CREDITS.md ประกอบโครงงาน

### เหตุผลที่ต้องแก้
รายงานฉบับเดิมระบุว่าถ่ายเองทั้งหมด แต่ในทางปฏิบัติจริงได้ขออนุญาตอาจารย์เปลี่ยนมาใช้ข้อมูลจากอินเทอร์เน็ตแทน — ถ้าส่งรายงานที่ข้อความไม่ตรงกับความจริง อาจถือเป็นข้อมูลเท็จทางวิชาการ

## 2. แก้ไขเงื่อนไขรูปภาพ (ส่วนที่พูดถึง "หน้าตรงเท่านั้น")

### ข้อความเดิม (โดยสรุป)
> รับเฉพาะรูปถ่ายหน้าตรง ระยะ 1.5–3 เมตร ถ่ายตอนกลางวัน

### ข้อความที่แนะนำให้แก้เป็น
> รับรูปถ่ายมุมหน้าตรงหรือมุมหลังตรง (ไม่รองรับมุมเฉียง 3/4 หรือมุมข้าง) ระยะที่รถเต็มคันพอดีเฟรม ถ่ายตอนกลางวันหรือแสงสว่างเพียงพอ

### เหตุผลที่ต้องแก้
ระหว่างเก็บข้อมูลจริง พบว่าการจำกัดแค่ "หน้าตรง" ทำให้หารูปได้ยากเกินไป จึงขยายขอบเขตให้รับมุมหลังตรงด้วย ซึ่งยังคงตรงตามหลักการเดิม (เห็นป้ายเต็มแผ่น ไม่บิดเบี้ยว) แต่เพิ่มความยืดหยุ่นในการเก็บข้อมูล

## 3. เพิ่มผลการทดลองจริง (ส่วนผลลัพธ์/บทสรุป)

ใส่ตารางนี้แทนที่ผลลัพธ์ตัวอย่าง/ยังไม่มีในรายงานเดิม:

| ตัวชี้วัด | 5-Fold Cross-Validation (เฉลี่ย) | ชุดทดสอบ 50 รูป |
|---|---|---|
| Precision | 0.967 | 0.988 |
| Recall | 0.967 | 0.940 |
| mAP@0.5 | 0.986 | 0.954 |
| อัตราครอปสำเร็จ | - | 98.0% (49/50) |

ผลแต่ละ fold:

| Fold | Precision | Recall | mAP@0.5 |
|---|---|---|---|
| 1 | 0.952 | 0.996 | 0.990 |
| 2 | 0.936 | 0.951 | 0.970 |
| 3 | 1.000 | 0.993 | 0.995 (ดีที่สุด → ใช้เป็น best.pt) |
| 4 | 0.974 | 0.942 | 0.988 |
| 5 | 0.971 | 0.950 | 0.986 |

พร้อมอธิบายว่า **ค่าเฉลี่ย CV กับผล Test Set ใกล้เคียงกัน (ต่างกัน ~3 จุด)** ซึ่งยืนยันว่าโมเดลเรียนรู้ลักษณะทั่วไปของป้ายทะเบียนจริง ไม่ได้จดจำรูปในชุดฝึกสอน (ไม่เกิด overfitting)
