# ระบบตรวจจับและครอปป้ายทะเบียนไทยด้วย YOLO11

โครงงาน: ระบบตรวจจับและครอปป้ายทะเบียนรถไทย
ผู้จัดทำ: ธิติวุฒิ สุกทอง (รหัสนักศึกษา 6724650293)

## วิธีรันสำหรับผู้ตรวจ (Command Line)

ต้องใช้ Python 3.9 ขึ้นไป รันได้ทั้ง Windows / macOS / Linux (ไม่ต้องมี GPU เครื่องจะเลือกอุปกรณ์เองอัตโนมัติ: CUDA → MPS → CPU)

```bash
# 1. เข้าโฟลเดอร์โปรเจกต์ แล้วสร้าง virtual environment
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 2. ติดตั้ง library (ครั้งแรกครั้งเดียว ใช้เวลาสักครู่เพราะมี PyTorch)
pip install -r requirements-cli.txt

# 3. รันโปรแกรม แล้วพิมพ์ path รูปรถเองเมื่อโปรแกรมถาม (พิมพ์ q เพื่อออก)
python src/inference/predict_and_crop.py
```

ตัวอย่างการใช้งาน:

```bash
python src/inference/predict_and_crop.py                          # โหมดโต้ตอบ: โปรแกรมถาม path รูปเอง
python src/inference/predict_and_crop.py --image samples/plate_004.jpg
python src/inference/predict_and_crop.py --image รูป1.jpg รูป2.jpg # หลายรูป
python src/inference/predict_and_crop.py --image samples/         # ทั้งโฟลเดอร์
python src/inference/predict_and_crop.py --image car.jpg --out ผลลัพธ์.jpg
```

- **Input:** รูปรถ 1 คัน (JPG/PNG) ที่เห็นป้ายทะเบียนชัดเจน — มีรูปตัวอย่างให้ลองในโฟลเดอร์ `samples/`
- **Output:** รูปป้ายทะเบียนที่ครอปแล้ว (400×200 พิกเซล) บันทึกที่ `outputs/crops/<ชื่อรูป>_plate.jpg` พร้อมพิมพ์ค่าความมั่นใจ (confidence) บนหน้าจอ ถ้าไม่พบป้ายจะแจ้ง "ไม่พบป้ายทะเบียน"
- ตัวเลือกเสริม: `--conf` (ค่าความมั่นใจขั้นต่ำ, ค่าเริ่มต้น 0.6), `--iou` (NMS, 0.45), `--device cpu|mps|0`, `--out-dir` (โฟลเดอร์เก็บผลลัพธ์)
- ครั้งแรกที่รันอาจช้ากว่าปกติเล็กน้อยเพราะต้องโหลดโมเดล (`models/best.pt`, ~5 MB)

## เรื่อง Dataset ในแพ็กเกจที่ส่ง

**ชุดข้อมูลที่ใช้เทรน:** รูปรถไทย **250 รูป** (รถ 1 คันต่อ 1 รูป เห็นป้ายทะเบียนชัดเจน) เก็บจาก **Wikimedia Commons**
ตามที่อาจารย์อนุญาตให้ใช้ข้อมูลจากอินเทอร์เน็ต คัดจากที่ดาวน์โหลดทั้งหมด 416 รูป (ไม่ผ่านเกณฑ์ 166 รูป) ตรวจด้วยตาทีละรูป
ทุกรูปใช้สัญญาอนุญาตแบบเปิด (CC BY-SA 4.0 / CC0 / CC BY 2.0 / CC BY-SA 3.0 / CC BY 3.0 / Public domain ไม่มี ND) ผู้ถ่าย 19 ราย
ตีกรอบป้ายด้วย makesense.ai (class เดียว `license_plate`) แล้วแบ่งเป็น Test 50 รูป + Train 200 รูป (5-Fold Cross-Validation)
โดยกันรถคันเดียวกันไม่ให้ข้ามชุด รายละเอียดทั้งหมดอยู่ในรายงาน (Present.docx / Present.pdf บทที่ 2)

| รายการ | อยู่ในแพ็กเกจนี้? | หมายเหตุ |
|---|---|---|
| `models/best.pt` (โมเดลที่เทรนแล้ว) | มี | **ใช้รันตรวจจับได้เลย ไม่ต้องใช้ dataset** |
| `data/raw/dataset_manifest.csv` | มี | บันทึกที่มา ผู้ถ่าย สัญญาอนุญาต ลิงก์ต้นทาง และ SHA-256 ของทั้ง 416 รูป |
| `data/raw/CREDITS.md` | มี | สรุปแหล่งที่มา 5 รอบ และบทเรียนการเก็บข้อมูล |
| `data/labels/` (label 250 ไฟล์) | มี | ไฟล์ YOLO format (ขนาดเล็ก) |
| `data/classes.txt` | มี | ชื่อคลาส |
| `samples/` | มี | รูปตัวอย่าง 3 รูปสำหรับทดสอบรัน (พร้อมเครดิตผู้ถ่าย) |
| รูปต้นฉบับ 250 รูป (`data/raw/*.jpg`, ~70 MB) | **ไม่มี** | ตัดออกเพื่อลดขนาดไฟล์ (ดาวน์โหลดซ้ำได้จากลิงก์ `source_url` ใน manifest) |

| ผลเทรนทุก fold (`outputs/predictions/runs/`) | ไม่มี | มีไฟล์สรุปผล `cv_summary.csv`, `test_set_summary.csv` แทน |

**การรันโมเดลตรวจจับไม่ต้องใช้รูปชุดข้อมูลเลย** ใช้แค่ `models/best.pt` กับรูปรถที่ผู้ตรวจเลือกเอง
รูปชุดข้อมูลจำเป็นเฉพาะกรณีต้องการเทรนหรือประเมินซ้ำ (`src/train/`) ซึ่งทำได้โดยดาวน์โหลดรูปตาม `source_url`
ใน manifest ใส่ไว้ที่ `data/raw/` แล้วรัน `src/data_prep/split_folds.py` ตามขั้นตอนด้านล่าง

## สรุปโครงงาน

รับรูปถ่ายรถ 1 คัน (หน้าตรงหรือมุมหลังตรง ที่เห็นป้ายทะเบียนชัดเจน) แล้วใช้โมเดล YOLO11 (yolo11n)
หาตำแหน่งป้ายทะเบียนในรูป จากนั้นตัดเฉพาะส่วนที่เป็นป้ายออกมาเป็นรูปใหม่ด้วย OpenCV

ข้อมูลฝึกโมเดลเก็บจาก **Wikimedia Commons** (สัญญาอนุญาต CC) ตามที่อาจารย์อนุญาตให้ใช้ข้อมูลจากอินเทอร์เน็ตได้
(ดูรายละเอียดและแหล่งที่มาทุกไฟล์ที่ [data/raw/CREDITS.md](data/raw/CREDITS.md))

| Input | Output |
|---|---|
| รูปภาพรถ 1 คันที่มีป้ายทะเบียน | รูปภาพป้ายทะเบียนที่ครอปออกมาจากรูป Input (400×200 พิกเซล) |

## ผลลัพธ์จริง (อัปเดตล่าสุด)

| ตัวชี้วัด | 5-Fold Cross-Validation (เฉลี่ย) | ชุดทดสอบ 50 รูป (ไม่เคยเห็นระหว่างเทรน) |
|---|---|---|
| Precision | 0.967 | 0.988 |
| Recall | 0.967 | 0.940 |
| mAP@0.5 | 0.986 | 0.954 |
| อัตราครอปสำเร็จ (IoU ≥ 0.5) | - | **98.0% (49/50)** |

ผลจาก CV และ Test Set ใกล้เคียงกันมาก (ต่างกัน ~3 จุด) ยืนยันว่าโมเดลเรียนรู้ลักษณะทั่วไปของป้ายทะเบียนจริง ไม่ได้จำรูปในชุดเทรน — นำไปใช้กับรูปรถคันใหม่ที่ไม่เคยเห็นมาก่อนได้

รายละเอียดผลแต่ละ fold ดูที่ `outputs/predictions/cv_summary.csv` และ `outputs/predictions/test_set_summary.csv`

## ขั้นตอนการทำงานของระบบ

1. **รับรูป** — ผู้ใช้อัปโหลดรูปรถ 1 คัน (หน้าตรงหรือมุมหลังตรง)
2. **หาป้าย** — YOLO11 (`models/best.pt`) ตรวจจับตำแหน่งป้ายทะเบียน ได้กรอบสี่เหลี่ยม + ค่าความมั่นใจ (ultralytics จัดการ resize/preprocessing ให้อัตโนมัติ)
3. **คัดกรองผล** — ตัดกรอบที่มั่นใจ < 60% และตัดกรอบซ้อนกันออกด้วย NMS
4. **เลือกป้ายหลัก** — ถ้าเจอหลายป้าย เลือกกรอบที่ใหญ่ที่สุด (รถคันหลักในรูป)
5. **ครอปภาพ** — ตัดรูปด้วย OpenCV ให้ชิดขอบป้าย (ขยายขอบ 3 พิกเซล) ปรับขนาดผลลัพธ์เป็น 400×200 พิกเซล
6. **แสดงผล** — ส่งคืนรูปป้ายทะเบียนที่ครอปแล้ว

หากไม่พบป้ายทะเบียน ระบบแจ้งว่า "ไม่พบป้ายทะเบียน"

## ชุดข้อมูล

- เก็บรูปรถ **250 คัน** (คันละ 1 รูป, หน้าตรงหรือมุมหลังตรงที่เห็นป้ายชัด) จาก Wikimedia Commons (สัญญาอนุญาต CC — ไม่มี ND) ตามที่อาจารย์อนุญาตให้ใช้ข้อมูลจากอินเทอร์เน็ตได้
- ชุดสอน (train pool): 200 รูป — ใช้ 5-Fold Cross-Validation (fold ละ ~40 รูป, 4 fold สอน/1 fold ตรวจ สลับ 5 รอบ)
- ชุดทดสอบ (test): 50 รูป — กันไว้ไม่ให้โมเดลเห็นเลยระหว่างเทรน/validate
- **กันรถคันเดียวกันข้ามชุด**: จัดกลุ่มจากชื่อไฟล์ต้นฉบับใน dataset_manifest.csv ก่อนแบ่ง ตรวจสอบแล้วไม่มีรถคันเดียวกันหลุดข้ามชุดสอน/ทดสอบ/fold เลย
- ตีกรอบป้าย (label) ด้วย [makesense.ai](https://www.makesense.ai) (เว็บแอป ไม่ต้องติดตั้ง) ตรวจสอบความถูกต้องแล้วทั้ง format อัตโนมัติและด้วยตา

## ตัวชี้วัดผลลัพธ์

| ตัวชี้วัด | ความหมาย |
|---|---|
| Precision | กรอบที่โมเดลบอกว่าเป็นป้าย ถูกจริงกี่เปอร์เซ็นต์ |
| Recall | ป้ายทั้งหมดในรูป หาเจอกี่เปอร์เซ็นต์ |
| mAP@0.5 | คะแนนรวมของการตรวจจับ (IoU ≥ 50%) |
| อัตราครอปสำเร็จ | จำนวนรูปทดสอบที่ตรวจจับตำแหน่งป้ายตรงกับกรอบจริง (IoU ≥ 0.5) หารด้วย 50 รูป |

ดูตารางผลจริงที่หัวข้อ "ผลลัพธ์จริง" ด้านบน

## ข้อจำกัด

- รองรับเฉพาะรูปหน้าตรงหรือมุมหลังตรง (มุมเอียง 3/4 หรือมุมข้างไม่รองรับ)
- ป้ายแดง (ป้ายทะเบียนชั่วคราว/เต็นท์รถ) มีตัวอย่างในชุดเทรนน้อย โมเดลอาจพลาดได้ง่ายกว่าป้ายขาวทั่วไป โดยเฉพาะถ่ายมุมเฉียงในแสงน้อย (ดูตัวอย่างจริงใน error analysis)
- ข้อมูลสอนมีเพียง 200 รูป โมเดลอาจพลาดกับฉากที่ต่างจากที่เคยเห็นมาก
- ต่อยอดได้โดยเพิ่มรูปมุมเอียง ป้ายสีอื่นๆ และช่วงเวลาอื่น แล้วฝึกโมเดลใหม่

## วิธีใช้งาน

```bash
# 1. ติดตั้ง dependencies
pip install -r requirements.txt

# 2. (ถ้าต้องการเก็บรูปเพิ่ม) นำรูปใหม่เข้าระบบผ่าน ingest pipeline
python src/data_prep/ingest_images.py --input path/to/new_photos --source self

# 3. ตรวจสอบและแบ่งข้อมูลเป็น train/test + 5-fold
python src/data_prep/verify_labels.py
python src/data_prep/split_folds.py

# 4. ฝึกโมเดล (5-Fold Cross-Validation, ทีละ fold ก็ได้)
python src/train/train_yolo11.py --epochs 100 --device mps

# 5. ประเมินผลกับชุดทดสอบ 50 รูป
python src/train/evaluate_test_set.py

# 6. รันตรวจจับ+ครอปป้ายจากรูปใหม่ (ไม่ใส่ --image = โปรแกรมถาม path รูปเอง)
python src/inference/predict_and_crop.py --image path/to/car.jpg

# 7. หรือใช้งานผ่านเว็บแอป
streamlit run src/app/streamlit_app.py
```
